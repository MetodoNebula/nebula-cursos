Opción 1B (2,5 p.):
Sea A una matriz cuadrada de orden 3 que cumple que A2 = O, donde O es la matriz nula
de orden 3 (todos sus elementos son cero).

    a) (0,75 p.) Compruebe que (A + I)2 = 2A + I, y que (A + I)3 = 3A + I, donde I es la
       matriz identidad de orden 3.

    b) (0,75 p.) Compruebe que las matrices I − A e I + A son mutuamente inversas.

    c) (1 p.) Resuelva la ecuación matricial X + AX = A expresando X en función de A.

Solución: a) Tenemos que

                       (A + I)2 = A2 + 2A + I = O + 2A + I = 2A + I,

y
                 (A + I)3 = A3 + 3A2 + 3A + I = O + 3O + 3A + I = 3A + I,
porque
                                   A3 = A2 · A = O · A = O.
b) Tenemos que
                           (I + A) · (I − A) = I 2 − A2 = I − O = I.
Lo mismo puede hacerse con (I − A) · (I + A).
c) Tenemos que, usando (b),

                            X + AX = A ⇐⇒ (I + A) · X = A ⇐⇒
                            (I − A) · (I + A) · X = (I − A) · A ⇐⇒
                           X = (I − A) · A = A − A2 = A − O = A.

Es decir, X = A.
